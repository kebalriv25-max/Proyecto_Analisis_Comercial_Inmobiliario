# Proyecto Análisis Comercial Inmobiliario
El objetivo de este proyecto fue evaluar el desempeño comercial en el sector inmobiliario para comprender su crecimiento, rentabilidad y comportamiento de clientes.

## Se trabajara con el siguiente dataset: 
- **hecho_ventas_propiedades.csv** → Cada fila representa la transacción de venta de una propiedad.
- **dim_clientes.csv** → Cada fila representa un cliente.
- **dim_propiedades.csv** → Cada fila representa una propiedad disponible para venta.

## 📂 Contenido del repositorio

- `Proyecto_InmobiliarioGrupoAndes.ipynb`
  → Notebook principal con la estructura del dashboard, criterios comparación de gastos promedio, tasas de conversión, visualizaciones y conclusiones.

## ▶ Cómo abrir el notebook en Google Colab

Haz clic en el siguiente botón:

1. Abre el archivo `Proyecto_InmobiliarioGrupoAndes.ipynb` en GitHub para conocer el proceso detallado realizado en el dashboard.
2. Haz clic en **Open in Colab**.

## 📘 Cómo reproducir el análisis

1. Abre `Proyecto_InmobiliarioGrupoAndes.ipynb` y el enlace al arhivo .pbix en el siguiente [enlace](https://drive.google.com/file/d/1qkUa69ERNb4XAAEtsa0Q52z6XJZkqHGq/view?usp=sharing)
2. Visualiza las celdas en orden
3. El arhivo pbix carga automáticamente los dataset 
## 🧠 Objetivo del análisis
se realizara lo siguiente:
- 🔍 Preparar y validar datos para análisis.
- 🔁 Construir un modelo de datos en esquema estrella.
- 🛒 Crear medidas analíticas para análisis comercial.
- 🧪 Aplicar inteligencia de tiempo para analizar tendencias.
- 📊 Diseñar dashboards claros para análisis ejecutivo.
- 💰 Analizar la recurrencia de clientes utilizando cohortes.
